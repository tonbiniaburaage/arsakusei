# DREAMY OCEAN — 光る海の水族館

PC・モニター・固定カメラで常時運転する、展示用のインタラクティブ水族館です。

カメラが映す現実の風景の上に、2Dの魚群・泡・水中の光を合成します。カメラの前で模型や手が動くと、検出位置に光の波紋が広がり、魚群が一時的に活発に泳ぎます。

## 現在の段階

- PC用固定カメラを自動起動
- 実写カメラ映像の鏡像表示
- 弧を描く魚群、渦を巻く魚群、近景を横切る魚
- 泡、水面から差す光、青い水中カラー
- 低解像度の差分比較による軽量な動作位置検出
- 動きに反応する光の波紋と魚群の加速
- MediaPipe Gesture Recognizerによる最大2手のローカル認識
- 開いた手でタコ、握りこぶしでフグ、Vサインでカニを召喚
- 開いた両手を近づけると大きなカニを召喚
- 12回中8回の多数決、ポーズ別保持時間、2.5秒のクールダウンで誤発動を抑制
- 左下の半透明手形、円形進捗、泡による非言語フィードバック
- 起動失敗時だけ表示される再試行ボタン
- キーボードの `F`、または画面内ボタンによる全画面表示

MindAR、Three.js、旧ARカード認識、スタンプ、ミニゲームは現在のトップページからは読み込みません。旧コードは次の演出を作り直す際の参考用として残しています。

## 起動方法

カメラは `file://` では起動できません。localhostのWebサーバーか、HTTPSで配信します。

```powershell
python -m http.server 8000
```

ChromeまたはEdgeで `http://localhost:8000/` を開き、初回だけカメラを許可します。次回以降はページ起動後に自動でカメラ映像へ移行します。

## 現在使用するファイル

```text
index.html                 常設展示画面
styles.css                 展示レイアウト・水中カラー
src/main.js                カメラ起動・描画ループ・全画面制御
src/ambient-ocean.js       2D魚群・泡・光・反応波紋
src/motion-detector.js     カメラ映像の動作位置検出
src/gesture-controller.js  MediaPipe認識・安定化・召喚判定
src/gesture-config.js      信頼度・ROI・保持時間などの調整値
vendor/mediapipe/          固定配置したMediaPipe Tasks Vision 1.0.1とWASM
assets/models/gesture_recognizer.task  手ジェスチャー認識モデル
```

カメラ映像はブラウザ内のMediaPipeだけで処理します。録画、アップロード、外部送信は行いません。

カメラなしで召喚演出だけを確認する場合は `http://localhost:8000/?preview=1` を開きます。
