# DREAMY OCEAN — 光る海の水族館

PC・1920×1080モニター・固定カメラで常時運転する、展示用のインタラクティブ水族館です。

カメラが映す現実の風景の上に、2Dの魚群・泡・水中の光を合成します。手の位置と動きがそのまま海の引力や水流になり、魚群が待ち時間なく反応します。

## 現在の段階

- PC用固定カメラを自動起動
- WebGLシェーダーによる実写カメラ映像の水中屈折、コースティクス、色補正
- Boids方式で互いの距離・方向・まとまりを判断する8つ・合計200匹の魚群。大小の濃青・水色・白い魚シルエットを待機背景に表示
- 大小48個の泡、水面から差す光、多層波紋、青い水中カラー
- 高頻度の差分比較による、人物の動きへの素早い反応
- 動きに反応する光の波紋と魚群の加速
- MediaPipe Gesture Recognizerによる最大6手のローカル認識（最大3人を想定）
- 片手をかざすと魚が集まり、手を外すと魚群が一斉に散開
- 手を素早く振ると、その方向へ水流と魚群が流れる
- 腕を大きく回すと渦潮が発生し、56匹の魚が円形の群れになって回転
- 両手を3秒かざすと光をチャージし、左右どちらかへ光のクジラが約3秒で横断
- 人差し指を出し直すたびに3段階までちんあなごが増加
- ピースを出し直すとカニが現れ、3回目は10匹が追加される
- 認識開始直後から光の輪と魚群が動く、判定待ちのない即時フィードバック
- 手形アイコンを使わず、画面上部の横長ジェスチャーヒントとゲージで現在の反応を表示
- 人差し指の判定中と両手チャージ中は、その手に魚を集めない
- 片手は短い認識抜けを補完し、近くの魚群が自然に集まる
- 両手チャージは、左右の手を実際に近づけた後だけ開始
- カメラ映像は明るさを残し、水中シェーダーだけ30fpsで更新して魚の60fps描画と処理を分離
- WebGLを利用できないPCでは従来のカメラ表示へ自動的に切り替え
- 起動失敗時だけ表示される再試行ボタン
- キーボードの `F`、または画面内ボタンによる全画面表示

MindAR、Three.js、旧ARカード認識、スタンプ、ミニゲームは現在のトップページからは読み込みません。旧コードは次の演出を作り直す際の参考用として残しています。

## 起動方法

カメラは `file://` では起動できません。localhostのWebサーバーか、HTTPSで配信します。

```powershell
python -m http.server 8000
```

ChromeまたはEdgeで `http://localhost:8000/` を開き、初回だけカメラを許可します。次回以降はページ起動後に自動でカメラ映像へ移行します。

PC展示版では `.mjs` と `.wasm` を正しい形式で配信する必要があります。Node.jsが利用できる場合は、プロジェクトのフォルダーで次を実行します。

```powershell
node tools/exhibition-server.mjs
```

その後、`http://127.0.0.1:8004/index.html` をChromeまたはEdgeで開きます。

## 現在使用するファイル

```text
index.html                 常設展示画面
styles.css                 展示レイアウト・水中カラー
src/main.js                カメラ起動・描画ループ・全画面制御
src/water-renderer.js      WebGL水中シェーダー・映像屈折・コースティクス
src/ambient-ocean.js       Boids魚群・既存2D演出・多層反応波紋
src/motion-detector.js     高頻度のカメラ映像動作位置検出
src/gesture-controller.js  MediaPipe認識・手の速度・円運動・両手チャージ判定
src/gesture-config.js      旧ポーズ召喚版の設定（参考用）
vendor/mediapipe/          固定配置したMediaPipe Tasks Vision 1.0.1とWASM
assets/models/gesture_recognizer.task  手ジェスチャー認識モデル
```

カメラ映像はブラウザ内のMediaPipeだけで処理します。録画、アップロード、外部送信は行いません。

カメラなしで一連の反応を確認する場合は `http://localhost:8000/?preview=1` を開きます。「集まる→流れる→散る→渦潮→両手チャージ→クジラ横断→ちんあなご→カニ」が自動再生されます。
