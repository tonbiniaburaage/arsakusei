# ドリーミー海のなかま AR

レジン模型と一緒に置いた認識カードをスマートフォンで映すと、クラゲ・クジラ・ウミガメを判定し、海の生物が泳ぎ出すWebAR作品です。インストールは不要です。

## 現在の段階

Phase 1〜7を実装済みです。

- 3種類の認識カードをMindARで自動判定
- クラゲカードは全体・左側・下側の3ターゲットと紫色の補助判定に対応。ターゲット切替時は常に1体だけ表示し、部分画像の幅差も補正
- 3種類とも提供デザインを活かした透明背景の2D Sprite
- クラゲ1体が中央付近を小さくゆっくり漂い、画面外へ出にくい安定アニメーション
- クラゲ「泡ぷちリズム」、クジラ「長押しウェーブチャージ」、ウミガメ「甲羅ぐるぐる磨き」
- 生物ごとに異なる星・泡・水しぶき・花びら・光の軽量演出
- クジラの1〜3段階で高くなる波と、3回目の画面全面ウェーブ
- 成功後2.7秒の渦巻く光収集、左上の光るスタンプ帳、海中光線・水面反射・泡・光のリングを重ねた3種類コンプリート演出
- カードを見失っても1.8秒保持し、0.5秒でフェード。5秒以内に再認識するとゲーム途中から再開
- 3種類コンプリート時は、外部音声ファイルを使わない軽量な「海のファンファーレ」を再生
- しゅわしゅわ立ち上がる泡、驚きリアクション、30%で現れるミニアヒルなど短いコミカル演出
- 3種類で異なる画面内遊泳と、手ブレを抑える適応型平滑化
- Web Audio APIによる泡ぷち・潮吹き・甲羅磨き音（外部音声ファイル不要）
- カメラ映像・2Dキャラクター・演出を合成したAR写真
- 共有シートまたは画像保存へのフォールバック
- 低性能端末向けのPixelRatio・演出数自動調整
- 1ボタンでクラゲ→クジラ→ウミガメへ自動遷移する3種類デモ
- 特別クリア演出のあとに「おしまい」を表示
- URLを開いた直後のカメラ自動起動と、失敗時だけ表示するワンタップ再試行

## 実機で確認する

カメラ利用にはHTTPSが必要です。スマートフォンではGitHub PagesのURLをSafariまたはChromeで開いてください。

1. `target-card.html` をPCや別端末に表示するか、3枚をカラー印刷する
2. 対応するレジン模型をカードの白い部分へ置く
3. スマートフォンでトップページを開き、カメラを許可する。自動起動に失敗した場合だけ画面のボタンをタップする
4. 最初はカード全体を映す。クラゲは斜め・一部分だけでも補助判定できます
5. 表示された簡単なゲームを遊ぶ（クラゲ5回、クジラ3回、ウミガメは約3秒磨く）
6. クリア後、模型から集まる光と左上のスタンプを確認する
7. 必要なときだけ左下の丸いボタンでAR写真を撮る。右下の「やり直し」で現在のゲームを再開できる

透明なレジン模型だけを背景や角度が変わる状態で直接判定する方式ではありません。反射と透過の影響を避けるため、文字・色・四隅の模様を持つ認識カードを補助に使います。白い部分へ模型を置いても、左側と外周の特徴で判定できるよう認識データを生成しています。

## PCで確認する

```powershell
python -m http.server 8000
```

`http://localhost:8000/?demo=1` を開き、「3種類のデモを見る」を押します。クラゲ、クジラ、ウミガメの順で、カメラやカードなしでも全演出を確認できます。

## 現在の2D表現

3種類とも元画像のキャラクターデザインを維持した透明背景PNGを読み込みます。

- キャラクター本体を描き直さないため、元画像の顔・色・星柄を維持
- クラゲは大きな1体が中央付近をゆっくり小さく移動
- クラゲは奥行き方向の移動と拡大縮小をなくし、画面上で一定サイズを保って遊泳
- 全体・左側・下側ターゲット間の切替時に旧表示を即座に隠し、左側画像の390px／全体画像の900pxという基準幅差を補正
- クジラは長押しごとに波が高くなり、3回目に画面全面の大波を合成
- クジラは8の字、ウミガメは四隅、クラゲは中央付近の小さな波形を基調に別々の軌道で遊泳
- ウミガメは甲羅を指でぐるぐる磨くと、約3秒で宝石のように発光
- ウミガメの甲羅を囲む時計回り矢印で、磨く方向を案内
- 3種類とも成功表示のあと、模型から画面中央へ光が渦巻いて吸い込まれ、左上へキャラクタースタンプが押される
- スタンプは同じタブの間保持され、3種類そろうと「海の光、コンプリート！」演出へ進む
- 難易度は展示で短時間に遊べるよう、タップ操作でも進行する易しい設定
- カメラ映像と一緒にAR写真へ保存可能

Xperia相当のAndroid 14／Chrome環境（412×915 CSS px、DPR 2.625、5点タッチ）で、縦画面レイアウト、Pointer Events、WebGL、カメラAPIの利用可否を確認済みです。実機固有のカメラ画質・権限UIは会場端末で最終確認します。

## 主な構成

```text
index.html                         AR画面
target-card.html                   3種類のカード表示・印刷
sound-preview.html                 クリア音5種類のスマホ試聴ページ
assets/targets/creature-targets.mind  3種類・5ターゲットの認識データ
assets/sprites/dreamy-jellyfish-source.png  クラゲ2D素材
assets/sprites/dreamy-jellyfish-stamp.png   背景透過済みのクラゲスタンプ素材
assets/sprites/dreamy-whale-source.png      クジラ2D素材
assets/sprites/dreamy-turtle-source.png     ウミガメ2D素材
assets/sprites/mini-duck-surprise.png       30%演出のミニアヒル
src/tracking-engine.js             MindAR複数ターゲット追跡
src/creature-controller.js         生物の読込・遊泳
src/effect-controller.js           3種類のゲームと演出
src/sound-controller.js            操作音・成功音
src/photo-controller.js            AR写真の合成・共有
src/creature-config.js             3種類の設定と端末品質判定
EXHIBITION_CHECKLIST.md            展示前・当日の確認表
```

基本認識は画像ターゲット基準です。クラゲのみ、カードや模型の紫色が一部見えていれば反応する簡易フォールバックも併用します。これは厳密な物体認識ではないため、紫色の別の物へ反応する場合があります。
