# ドリーミー海のなかま AR

スマートフォンのカメラ映像に Three.js の3D生物を表示する、インストール不要のWebAR作品です。

## 現在の段階

Phase 3まで動作します。

- スマートフォンの背面カメラを起動
- MindARでテスト用画像カードを追跡
- 画像カードを基準にThree.jsの3Dモデルを固定
- 大1、中2、小2のクラゲを異なる軌道・速度・位相で表示
- `assets/models/jellyfish.glb` がない場合は軽量な仮クラゲを表示
- `?creature=jellyfish` / `whale` / `turtle` で設定を切り替え
- 端末負荷を抑えるため描画PixelRatioを最大1.5に制限
- 「カメラなしで5匹の動きを見る」でPC上の3D確認が可能

## 確認方法

カメラにはHTTPSまたはlocalhostが必要です。

```powershell
python -m http.server 8000
```

PCでは `http://localhost:8000` を開きます。スマートフォン実機ではGitHub PagesのHTTPS URLを使ってください。

### Phase 2・3の確認

1. 最初の端末で `target-card.html` を開くか、カード画像を印刷
2. 別のスマートフォンでトップページを開く
3. 「ARをはじめる」を押してカメラを許可
4. テスト用カード全体を画面の枠に入れる
5. 5匹のクラゲが現れたら、スマートフォンをゆっくり左右・上下に動かす

カードを基準に見える角度が変わればPhase 2、5匹が異なる軌道で泳げばPhase 3の確認完了です。

## モデルの配置

以下にGLBを置くと仮モデルから自動的に置き換わります。

```text
assets/models/jellyfish.glb
assets/models/whale.glb
assets/models/turtle.glb
```

推奨目安は、1モデル5MB以下、テクスチャ1024px以下、アニメーション1〜2本です。

## 実装フェーズ

1. カメラ上に3Dモデル1匹を表示（完了）
2. 画像マーカーを起点に現実空間へ配置（仮ターゲットで完了）
3. 4〜5匹の自然な遊泳（クラゲで完了）
4. カメラ映像とARの写真保存
5. 星・泡・光の軽量演出
6. 生物Configの完成
7. 展示環境で認識と性能を安定化
