# ドリーミー海のなかま AR — iPad mini 常設版

光るレジン模型をiPad mini第6世代のカメラに映すと、クラゲ・クジラ・ウミガメを端末内で判定し、それぞれのARゲームが自動で始まる展示作品です。インストールは不要です。

## 現在の仕様

- 添付された3枚の実物模型写真から、紫〜青色の透過色と輪郭を低解像度で照合
- iPadの内カメラ（画面側）を明示的に使用
- クラゲ、クジラ、ウミガメを安定フレームの多数決で判定し、対応ゲームを自動開始
- 写真入りカードと白地補助カードをMindARで認識
- 一度ゲームが始まると対象をロックし、模型が画面外へ移動しても最後の位置で演出を継続
- 光のスタンプが押されるまで、認識喪失や別模型への切替を無視
- 暗所ではフレームの明るさ分布から最大3.4倍まで検出用ゲインを自動補正
- 対応端末では露出・フォーカス・ホワイトバランスを連続自動調整
- iPad mini第6世代向けに通常画質へ固定。軽量モードへの自動切替は行わない
- 描画は30fps、Pixel Ratioは最大1.5、パーティクルは最大160個に固定し、常設時の発熱とメモリ増加を抑制
- クラゲ「泡ぷちリズム」、クジラ「長押しウェーブチャージ」、ウミガメ「甲羅ぐるぐる磨き」
- 3種類の光るスタンプとコンプリート演出
- カメラを使わない3種類連続デモ

画像処理はブラウザ内だけで行います。カメラ映像や判定画像は保存・送信しません。

## iPad miniで起動する

カメラ利用にはHTTPSが必要です。iPad mini第6世代のSafariで公開URLを開きます。

1. iPadを展示位置へ固定する
2. トップページを開き、初回だけカメラを許可する
3. 光る模型を1体ずつ、画面中央付近へ置く
4. 種類名が表示され、対応ゲームが自動で始まることを確認する
5. ゲーム開始後は模型を外してもよい。スタンプ取得まで演出は継続する
6. 次の案内が出たら別の模型を映す

暗い会場では模型自体を点灯させ、背景と輪郭が分かれる距離に置いてください。完全な暗闇や、模型と同じ紫色の大きな物体が背景にある状態では誤判定しやすくなります。

## PCで演出を確認する

ローカルWebサーバーで公開し、`http://localhost:8000/?demo=1` を開きます。「3種類のデモを見る」を押すと、カメラや模型なしで全演出を確認できます。

## 認識方式

`src/resin-model-detector.js` は160×120ピクセル、約6回/秒でカメラを走査します。

- 画面の明るさ分布から検出用ゲインを調整
- 紫〜青色の透過レジン候補を抽出
- 最大の連結領域から縦横比、密度、上下分布、12×12輪郭記述子を生成
- 添付された各模型写真の記述子と比較
- 直近7回のうち4回以上一致した種類だけを採用

高速な低解像度処理で、認識中も履歴・配列が無制限に増えない構造です。平面カードが映った場合はMindARの画像追跡が優先されます。

## 主な構成

```text
index.html                                    AR画面
assets/targets/resin-jellyfish-reference.png  クラゲ模型の参照画像
assets/targets/resin-whale-reference.png      クジラ模型の参照画像
assets/targets/resin-turtle-reference.png     ウミガメ模型の参照画像
assets/targets/creature-targets.mind           従来カード用の補助認識データ
assets/sprites/                                3種類の2D演出素材
src/resin-model-detector.js                    暗所補正・模型分類・安定化
src/tracking-engine.js                         模型／カード認識とゲームロック
src/creature-controller.js                     生物の読込・遊泳
src/effect-controller.js                       3種類のゲームと演出
src/sound-controller.js                        操作音・成功音
src/photo-controller.js                        AR写真の合成・共有
src/creature-config.js                         iPad mini常設画質設定
EXHIBITION_CHECKLIST.md                         展示前・当日の確認表
```

## 実機調整

参照写真は現在の3模型に合わせています。照明、模型の発光色、設置距離が大きく変わる場合は、会場のiPadカメラで撮った写真へ参照画像を差し替えて再調整してください。Webブラウザだけで行う輪郭照合のため、あらゆる角度の3D物体を保証する汎用AI物体認識ではありません。
